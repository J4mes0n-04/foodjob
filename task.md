
# Сервис управления питанием

В технохабе действуют несколько сервисов по питанию, предоставляя различный перечень услуг.

### Кофейня на первом этаже «...лось»

Предоставляются услуги кофе/чай в широком ассортименте, салаты и завтраки. Из «фишек» кофейни — можно также покупать дроп-пакеты с понравившимся видом кофе. Взаимодействие с клиентами — только оффлайн (ранее был канал в тг, сейчас нет).	

### Кафе на первом этаже с зоной раздачи «Без названия»

Полный спектр обслуживания по питанию. Кроме зоны раздачи, которая работает в режиме завтраков и бизнес-ланчей, есть также три тематических зоны, работающих со своим ассортиментом — зоны «Франция», «Италия», «Азия». В каждой из зон предоставляются различные услуги — например, в зоне «Франция» действует дисконтная система на напитки, в зоне «Азия» работает комплекс «азиатский бизнес-ланч». В кафе проводятся различные активности — это дни национальной кухни, мастер-классы, музыкальные перфомансы. Из дополнительных услуг — можно делать заказы на различные мероприятия команды (пицца, торты и т.п.).
Взаимодействие с клиентами — есть оффлайн (доска замечаний и предложений), онлайн - «Патруль качества» (чат в тг). Также есть отдельное приложение с широким функционалом (это и меню, новости, а также сервис заказа еды на этаж).

### Кофейня на 14-м этаже «Высота»

Предоставляются услуги кофе/чай в широком ассортименте, салаты и завтраки. Из «фишек» кофейни — находится рядом с выходом на террасу. Из особенностей — иногда закрывается на работу в режиме кофе-брейков при проведении мероприятий на 14-м этаже.  Взаимодействие с клиентами — только оффлайн.

### Сервис смарт-холодильников на этажах (Самокат и Uvenco)

Предоставляется широкий ассортимент блюд, выпечки и напитков в режиме самообслуживания. Ранее у Uvenco было свое приложение с системой скидок, сейчас обслуживание унифицировано.
Взаимодействие с клиентами — через менеджера (онлайн — есть служба поддержки).

### Сервис чай/кофе/снэки  на этажах 

Предоставляется еженедельно обновляемый ассортимент снэков, а также чай и кофе в свободном доступе на кофе-пойнтах. Взаимодействие с клиентами — через менеджера.

### Что требуется сделать (гипотеза):

Создать платформу, которая могла бы объединить эти сервисы в единую систему с широким набором возможностей для работы партнеров и взаимодействия их с внутренними клиентами. Может быть реализована следующая ролевая модель:
- Пользователь. Может пользоваться всеми услугами через единый интерфейс (в том числе взаимодействовать с операторами отдельных сервисов)
- Партнер. Должна быть возможность подключения своих услуг, бонусной системы, интеграции с системами партнера
- Администратор платформы. Может добавлять партнеров на платформу, работа с пользователями платформы

В этом кейсе привествуются любые разумные решения/дополнительные сервисы по питанию.
